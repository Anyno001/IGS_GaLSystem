# 沉浸式 Galgame 系统

**Immersive Galgame System** 是一套面向 SillyTavern 的酒馆助手脚本，把聊天中的叙事内容整理成视觉小说式的阅读与场景演绎体验。

它提供对话框、旁白、选项、角色立绘、场景背景和状态信息等视觉层，并将正文解析、场景状态、图片素材和阅读器界面统一起来。你可以继续使用酒馆作为对话入口，也可以在阅读器中以更接近 Galgame 的方式浏览剧情。

## 主要功能

- **视觉小说阅读器**：对白、旁白、选项、分页和阅读状态管理。
- **角色与场景演出**：背景、角色立绘、表情、天气、光照、舞台动画和状态栏。
- **可调整的阅读界面**：多种对话框风格、字体、字号、工具栏、状态 HUD，以及桌面端、移动端和内嵌模式布局。
- **AI 图片与素材集成**：为场景背景和插图提供生成与资源管理入口，并支持本地素材缓存。
- **正文标签与演出效果**：场景标签、聊天块、打字机、音效、震动和其他视觉效果。
- **设置与预设管理**：统一设置面板、场景与阅读器预设、导入导出契约，以及对旧版设置的兼容读取。

## 快速开始

1. 下载 `loader/` 中当前版本的中文自动更新导入件：
   `酒馆助手脚本-沉浸式Galgame系统（自动更新） v0.34.39.json`（已导入旧版的用户无需重新导入，会自动更新）。
2. 将 JSON 导入 SillyTavern 的酒馆助手脚本。
3. 启用脚本，等待远程 bundle 加载完成。
4. 从酒馆助手的 `Gal模拟` 入口打开阅读器。

自动更新 loader 会从发布仓库的 `main` 分支加载 `app/dist/` 中的运行时 bundle 和样式。若只想锁定某个版本，可使用 `loader/沉浸式Galgame系统 v0.23.21.json` 这类固定版导入件。

## 更新日志

### v0.34.39（2026-10-04）· 恐怖演出、音乐和素材管理

从 v0.34.26 更新到 v0.34.39：**阅读器多了恐怖风格与背景音乐；素材可以更方便地整理、上传和下载，设置页面在手机上也更顺手。**

#### 🎬 剧情演出有了新的选择
- 「恐怖」世界观可选偏血腥、偏心理或两者兼有；剧情中的恐怖程度会跨楼层延续，也能在设置中限制上限。两套恐怖对话框会随着剧情逐渐变化，敲门、停电和低语等演出也能参与其中。
- 增加内置背景音乐：按剧情情绪切换曲目，也能从地点栏的音乐入口查看曲名、手动换下一首。默认音乐包按世界观下载，曲目鸣谢见 [`app/assets/bgm/CREDITS.md`](app/assets/bgm/CREDITS.md)；不会替你打开所有声音开关。
- 新手引导里可以快速选择演出风格、热闹程度和需要的声音；自定义演出组合切换档位时会先确认，还能撤销这次切换。

#### 🎨 立绘和图片生成更灵活
- 角色立绘可选开启轮廓增强，自选描边或投影、颜色和强度；编辑立绘时暂时关闭，方便看清原图。剧情 CG 也可选在对话框左侧显示说话人的裸体立绘头像，旁白时隐藏，默认关闭。
- 生图来源增加「柏宝绘」；非数据库生图的表情、头像、立绘和衣柜提示词可交给独立的「副 LLM」编写，未配置好时会提示。Q 版头像改为圆框头颈肩构图。
- 画失败的剧情 CG 可以按已有提示词单独重画；CG 库清扫时能删除已找不到对应楼层的图，相册批量删除也不再漏掉照片。

#### 🖼️ 素材更好找，也更好带走
- 场景与角色素材可以上传图片；素材预设可以确认后用当前素材覆盖，也能把图片一起导出。角色和场景区可分别下载当前筛选出的素材。
- 场景列表在手机上留出更多空间给名字：小图统一排在左侧，地址收进展开区，时间和天气差分放到「⋯」里；「下载本区素材」改为简洁的文字按钮。
- 生图素材、剧情 CG 和相册照片可存进酒馆本地图片文件夹，旧图片在读取时逐步迁移；酒馆图片接口不可用时仍使用浏览器存储。删除或重画图片时会清理不再引用的旧文件。
- 待确认的情绪词可手动一键交给 AI 归入已有情绪组；打开自动归类后，同一楼出现的新词会一起处理，不再每翻一页问一次。

#### ⚙️ 设置起来更顺手
- 图片多的设置页减少重复加载缩略图；素材菜单打开或手指点选时不再被小图刷新打断。输入长文字或密钥时先保留草稿，退出设置再保存；保存失败时保留面板并提示。
- 设置器记住上次打开的页签；标签解析可折叠，演出按六组摆放，阅读器的「面板玻璃」和生图的「副 LLM」也更容易找到。旧的文字对齐设置继续生效。

#### ⚠️ 老用户请留意
- 酒馆的「数据清理」可能将 `igs-*` 图片目录里的图片标作未引用；清理前不要直接勾选删除，以免丢失本地素材。
- 新增的恐怖与音乐演出都由设置控制。已安装的自动更新导入件无需重新导入，重新加载酒馆后会自动更新到新版。

### v0.34.24（2026-10-03）· 换一张角色卡，整个舞台都跟着换

从 v0.33.16 到 v0.34.24，一句话概括：**每张角色卡都有自己的场景和衣柜，角色的喜怒哀乐能画得更细；外语台词有中文译文，魔法星夜和童话小镇也能开场了。**

#### 🗂️ 每张角色卡，都是自己的小世界
- 场景、立绘、衣柜现在分「本卡」和「全局」。换角色卡时，先用这张卡的素材；缺的才从全局补。旧素材还在，不会擅自搬家。
- 喜欢一张卡的布置？可以把素材整包带走，再导入到另一处。单件或整批迁移也能在素材页直接完成。
- 素材页整理成「角色／场景／待确认／规则」四页；原有素材预设找回来了，新预设还能分别保存本卡和全局。套用前会告诉你替换哪些素材并留好备份。

#### 🎭 一张立绘不够？给角色画出二十种表情
- 在角色页就能生成默认立绘；表情差分可选 **8／12／16／20 张**，预设词库帮 AI 认出常见的不同叫法。以前选过的 18 档会按 20 档处理。
- 角色的发色、衣服和表情各管各的：DNA 管长相，服装词跟着整套差分走，表情不再被默认立绘的「面无表情」压掉。还可以写一句这个角色专属的表情注意事项。
- 画到一半停了、某几张失败了？点「继续生图」用存好的词补画，已画好的不用重来；单张也能重新生成并换种子。进度和失败原因会告诉你，不让按钮一直转圈。
- 状态栏头像可生成圆脸 Q 版；衣柜多了内置「裸体」项，生成时按当前角色作画，不把它混进普通服装库。

#### 📖 外语台词，也能读得明明白白
- 新增双语台词：外语原文配中文译文，可只看原文、只看译文，或把译文标在原文上方；电脑阅读时还可以按 **T** 临时切换。
- 注音可以选「交错／译文在上／按分句」。长句在部分手机内核放不下时，会自动换成能折行的排版，不必左右拖着看台词。
- 手机竖屏的内嵌阅读框和自动补画的背景会按竖屏尺寸处理；旋转屏幕时，阅读框也会重新适配横竖比例。

#### ✨ 魔法开场，换一套对话框气氛
- 「魔法」世界观加入施咒、魔药、猫头鹰送信等演出；想换画风，还有绢色古风的「青绿山水」和带波浪花边的「童话小镇」。
- 「魔法学院」对话框变成「魔法星夜」：星徽、薄纱和细线能随说话角色的学院换色；「墨夜」配色还可以自选装饰颜色。两侧细线保持两端渐隐。
- 花纹对话框高度现在可调到 **130%**。战斗演出跟着对话框皮肤换色；汇文明朝体、悠哉字体文件也已修好，选中后不再静默回退。

#### ⚠️ 老用户请留意
- 原有素材默认留在全局；要让它只跟某张角色卡走，再使用「本卡／全局」迁移。套用预设前看清替换范围，备份会自动保存。
- 双语台词需要在阅读器演出设置中启用。新世界观演出仍按各自开关控制，不会替你打开所有演出。
