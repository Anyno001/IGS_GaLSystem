# 沉浸式 Galgame 系统

**Immersive Galgame System** 是一套面向 SillyTavern 的酒馆助手脚本，把聊天中的叙事内容整理成视觉小说式的阅读与场景演绎体验。

它提供对话框、旁白、选项、角色立绘、场景背景和状态信息等视觉层，并将正文解析、场景状态、图片素材和阅读器界面统一起来。你可以继续使用酒馆作为对话入口，也可以在阅读器中以更接近 Galgame 的方式浏览剧情。

## 主要功能

- **视觉小说阅读器**：对白、旁白、选项、分页和阅读状态管理。
- **角色与场景演出**：背景、角色立绘、表情、天气、光照、舞台动画和状态栏。
- **可调整的阅读界面**：多种对话框风格、字体、字号、工具栏、状态 HUD，以及桌面端、移动端和内嵌模式布局。
- **AI 图片与素材集成**：为场景背景和插图提供生成与资源管理入口，并支持本地素材缓存。
- **正文标签与演出效果**：场景标签、聊天块、打字机、音效、震动和其他视觉效果。
- **设置与预设管理**：统一设置面板、场景与阅读器预设、导入导出契约，以及对旧版设置的兼容读取。

## 快速开始

1. 下载 `loader/` 中当前版本的中文自动更新导入件：
   `酒馆助手脚本-沉浸式Galgame系统（自动更新） v0.33.16.json`（已导入旧版的用户无需重新导入，会自动更新）。
2. 将 JSON 导入 SillyTavern 的酒馆助手脚本。
3. 启用脚本，等待远程 bundle 加载完成。
4. 从酒馆助手的 `Gal模拟` 入口打开阅读器。

自动更新 loader 会从发布仓库的 `main` 分支加载 `app/dist/` 中的运行时 bundle 和样式。若只想锁定某个版本，可使用 `loader/沉浸式Galgame系统 v0.23.21.json` 这类固定版导入件。

### v0.33.16（2026-10-02）· 一次跨越四个大版本的更新

从 v0.29.5 直接跳到 v0.33.16。一句话概括：**角色会换衣服了，舞台能同时站好几个人，72 个场景开箱即用，屏幕上还能飘弹幕。**

> 新演出默认全部关闭，免得打扰老用户。想一口气体验，打开「设置 → 阅读器 → 演出」，在顶部「一键档位」点一下「推荐」或「全开」就行。

#### 🎨 72 个默认场景，下载就能用
素材库点「新增 → 下载默认素材」，一次拿到 **76 张背景图、72 个场景**，AI 写到对应地点时自动换上：
- **现代 54 个**：出租屋、少女卧室、街角咖啡馆、拉面馆、KTV 包厢、游戏厅、琴房、地下停车场、城中村巷道、汽车旅馆、酒店套房……
- **古风 18 个**：闺房、花厅、竹林小径、府邸长廊、后花园、假山、床帐内、马车内……
- 部分场景（比如公寓客厅）还有**夜晚和深夜**两个版本，天黑后自动换图。
- 每个场景都配了一组常见叫法。AI 写「电玩城」「街机厅」，都会认成「游戏厅」。

#### 👗 角色会换衣服了
- 给角色登记多套服装（校服、睡衣、泳装……），AI 写到换装时，立绘会**暗下去，再换新造型浮上来**。
- 服装可以绑定场景：在家穿的睡衣，出门后会自动换回来。
- 每套服装可以单独设状态栏头像。AI 写了没登记的服装名也不会出错，系统会记下来，等你一键归类。

#### 👥 多人同台（实验功能）
- 同一场景里最近说过话的角色**一起站在舞台上**，说话的人在前面，其他人稍微压暗。
- 换人说话时有交接动画，头部大小和高度会自动对齐；站位也可以自己拖。
- 拍照时，旁边的角色也会一起入镜。

#### 💬 弹幕来了
- **直播间模式**、**观众弹幕**、**角色内心弹幕**三种玩法。剧情说到要紧处，满屏弹幕刷屏的感觉就来了。

#### 🎬 演出大扩充
- **四类新演出**：日常、亲密、战斗、物品。打架有出招和受击，拿到道具有展示，日常小事也有动静。
- **14 种日常音效**：拍照快门、铃声、广播、烟花、闹钟、手机震动、抽签、小票、翻纸、便利贴……古风场景还有**更鼓、孔明灯和钟声**。
- **环境音**：雨声、风声、雷声、雪夜、鸟鸣、蝉鸣、虫鸣、人声、篝火、海浪、雨点敲窗，跟着天气和场景自动切换。
- **天气更细，画面跟着时间变色**：清晨、黄昏、深夜的色调都不一样，下雨天会更暗更冷（不喜欢夜间调色可以关掉）。
- **文字特效**：台词可以抖、可以起波浪，激动的话真的会「抖」出来。
- 日常事件 CG 会**停留几页**再离开，不会一闪而过；过场 CG 上限提高到 16 张。
- 亲密场景加入了声音和画面节奏（有单独开关，默认关闭）。

#### ✍️ 新字体
新增**站酷快乐体、汇文明朝、仓耳渔阳体**，以及 Great Vibes、Pinyon Script、IM Fell English 三款西文花体，古风、可爱、西幻都有对应的风格。字体改为按需加载，用到哪个字才下载哪一段，不会因为字体卡住。

#### 📖 读起来更舒服
- **自动播放**：工具栏一键开启，三档速度，和打字机速度同步。
- **新手引导**：第一次打开会手把手带你配置，连怎么翻页都会教。
- **内嵌模式**：点小铅笔直接改台词，改完自动刷新。
- **设置面板重新整理**：分类折叠、可以搜索，窄屏手机上也不挤；保存失败（比如存储满了）会直接告诉你原因。
- **地图换成明亮配色**，对话框、背景亮度、气泡尖角等细节都调整过。

#### 🖼️ AI 生图更聪明
- 新增 **CG 库**和**物品生图**，之后的场景背景和 CG 也会自动补上。
- 生图会带上**角色 DNA**，同一个角色每次画出来更像同一个人。
- 生成的素材可以跟着场景预设一起导出、分享；素材有保护，不会被误删。

#### ⚡ 更轻、更快
- 主程序体积减少约四分之一，打开更快。
- 切到别的页面时，天气动画和环境音会自动暂停，手机更省电。AI 流式输出时，内嵌阅读器也更流畅。

#### ⚠️ 老用户请留意
- NSFW 立绘改为三档，默认「仅露脸剪影」。
- 默认的场景注入规则已经自动升级，支持服装。如果你**自定义过注入规则**，请自己在规则里加上 `{{outfit_groups}}`，或者点「恢复默认」，不然 AI 不会写换装。
