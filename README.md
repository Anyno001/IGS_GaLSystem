# 沉浸式 Galgame 系统

**Immersive Galgame System** 是一套面向 SillyTavern 的酒馆助手脚本，把聊天中的叙事内容整理成视觉小说式的阅读与场景演绎体验。

它提供对话框、旁白、选项、角色立绘、场景背景和状态信息等视觉层，并将正文解析、场景状态、图片素材和阅读器界面统一起来。你可以继续使用酒馆作为对话入口，也可以在阅读器中以更接近 Galgame 的方式浏览剧情。

## 主要功能

- **视觉小说阅读器**：对白、旁白、选项、分页和阅读状态管理。
- **角色与场景演出**：背景、角色立绘、表情、天气、光照、舞台动画和状态栏。
- **可调整的阅读界面**：多种对话框风格、字体、字号、工具栏、状态 HUD，以及桌面端、移动端和内嵌模式布局。
- **AI 图片与素材集成**：为场景背景和插图提供生成与资源管理入口，并支持本地素材缓存。
- **正文标签与演出效果**：场景标签、聊天块、打字机、音效、震动和其他视觉效果。
- **设置与预设管理**：统一设置面板、场景与阅读器预设、导入导出契约，以及对旧版设置的兼容读取。

## 快速开始

1. 下载 `loader/` 中当前版本的中文自动更新导入件：
   `酒馆助手脚本-沉浸式Galgame系统（自动更新） v0.33.16.json`（已导入旧版的用户无需重新导入，会自动更新）。
2. 将 JSON 导入 SillyTavern 的酒馆助手脚本。
3. 启用脚本，等待远程 bundle 加载完成。
4. 从酒馆助手的 `Gal模拟` 入口打开阅读器。

自动更新 loader 会从发布仓库的 `main` 分支加载 `app/dist/` 中的运行时 bundle 和样式。若只想锁定某个版本，可使用 `loader/沉浸式Galgame系统 v0.23.21.json` 这类固定版导入件。

## 更新日志

### v0.33.16（2026-10-02）

这是从 v0.29.5 以来的一次大更新。**新增的演出效果默认都是关闭的**，可以在「设置 → 阅读器 → 演出」顶部用「一键档位」（全部关闭 / 轻量 / 推荐 / 全开）快速开启，也可以逐项打开。

**角色与立绘**
- 立绘支持服装差分：同一角色可以登记多套服装，AI 换装时立绘会带转场切换；服装可以设适用场景，也可以单独设状态栏头像。
- 多角色同屏（实验功能）：同一场景里最近说过话的角色会同时站台，说话人在前、其他人压暗，换人时有过渡动画；多人站位可以手动拖动调整。
- 角色 DNA 与抠图；数据库生图的 CG 也会带上角色 DNA，角色长相更稳定。
- NSFW 立绘改为三档，默认「仅露脸剪影」。

**演出**
- 新增亲密、战斗、物品、日常等演出，以及亲密场景的音效与节律音效（有单独开关）。
- 弹幕演出：直播间、观众弹幕与角色内心弹幕。
- 天气演出升级、天气细分；按时段和天气给画面调色，夜间调色可以单独关闭。
- 新增文字特效和漫画情绪符号（没有立绘时自动关闭情绪符号）。
- 日常事件 CG 会停留几页再消失；过场 CG 与素材数量上限提高到 16。

**阅读器与界面**
- 工具栏新增自动播放，有三档速度，和打字机共用设置页里的速度。
- 新手配置引导，会教你翻页等基本操作。
- 内嵌模式：点小铅笔可以直接编辑，编辑完自动重开；内嵌框按横竖尺寸固定。
- 设置面板重新整理：演出按分类折叠、支持搜索；适配细窄手机屏幕；保存失败或存储已满时会提示原因。
- 地图改为明亮配色；对话框可见性、背景亮度和气泡尖角等细节都有调整。

**素材与生图**
- 素材库新增「下载默认素材」，可以一键获取默认背景素材包。
- 新增生图 CG 库和物品生图；后续场景的 NSFW 图和背景也会自动生成。
- 生成的素材库可以随场景预设一起保存和导入导出；素材有保护，不会被误删。

**性能**
- 运行包体积变小，加载更快；大字体改为按需分片加载。
- 页面隐藏时暂停天气粒子和环境音，降低耗电；流式输出时内嵌阅读器更流畅。

**需要注意**
- 默认的场景注入规则已自动升级为带服装栏的新写法。如果你用的是自定义注入规则，需要自己在规则里加入 `{{outfit_groups}}`，或恢复默认规则，AI 才会输出服装。
- 角色卡或预设里自带的旧版隐藏正则，可能识别不了新的服装栏写法。
