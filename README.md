# 沉浸式 Galgame 系统

**Immersive Galgame System** 是一套面向 SillyTavern 的酒馆助手脚本，把聊天中的叙事内容整理成视觉小说式的阅读与场景演绎体验。

它提供对话框、旁白、选项、角色立绘、场景背景和状态信息等视觉层，并将正文解析、场景状态、图片素材和阅读器界面统一起来。你可以继续使用酒馆作为对话入口，也可以在阅读器中以更接近 Galgame 的方式浏览剧情。

## 主要功能

- **视觉小说阅读器**：对白、旁白、心里话、选项和分页，打字机逐字显示；桌面、手机与楼层内嵌三种布局，横竖屏自动适配。
- **会动的舞台**：场景背景随时段、天气换色，角色立绘按情绪切换表情、跟着说话人走位，多人同屏时没说话的角色也会有反应；支持特写、拉远、摇镜等镜头语言。
- **角色会出声**：台词开头按情绪播一声「啊、嗯、哼、诶？」这样的短语气音，23 套男女声线可按角色指定；内置 80 首背景音乐，按剧情情绪自动换曲，回忆、梦境里音乐会变闷，关键时刻会停下来留白。
- **丰富的剧情演出**：情绪漫画符号与集中线、来电与通话分屏、回忆和梦境滤镜、拍照、信件、烟花、猜拳、做饭、吃东西等几十种日常演出，以及战斗、亲密氛围、恐怖、弹幕等专题演出；全部由设置控制，按需开启。
- **拿到东西有存在感**：数据库物品表一更新就演出获得与失去，第一次拿到的物品在画面中央隆重登场，正文里的物品名可以点开查看；背包、地图、日记、好感度等资料页集中在状态栏里。
- **多种世界观与皮肤**：现代、古代、西幻、魔法、科幻、末日、大正、恐怖等世界观自动换装演出；十余套对话框皮肤（青绿山水、童话小镇、魔法学院、黑白漫画……），状态栏、选项和物品卡片都跟着换。
- **AI 图片与素材**：自动补场景背景、立绘、表情差分、剧情 CG 和物品图，支持 NovelAI、智绘姬、柏宝绘和数据库生图插件；素材可上传、分文件夹整理、打包导出，图片存进酒馆本地文件夹。
- **配置跟着酒馆走**：设置与预设同步到酒馆的本地文件，换设备、换浏览器、清缓存都还是同一份；统一设置面板带新手引导和演出风格问卷，出问题时可一键复制本页诊断。

## 快速开始

1. 下载 `loader/` 中当前版本的中文自动更新导入件：
   `酒馆助手脚本-沉浸式Galgame系统（自动更新） v0.34.74.json`（已导入旧版的用户无需重新导入，会自动更新）。
2. 将 JSON 导入 SillyTavern 的酒馆助手脚本。
3. 启用脚本，等待远程 bundle 加载完成。
4. 从酒馆助手的 `Gal模拟` 入口打开阅读器。

自动更新 loader 会从发布仓库的 `main` 分支加载 `app/dist/` 中的运行时 bundle 和样式。若只想锁定某个版本，可使用 `loader/沉浸式Galgame系统 v0.23.21.json` 这类固定版导入件。

#### 🎙️ 角色会出声了
- 新增「角色语气音」（默认关闭）：台词开头按情绪播一声「啊、嗯、哼、诶？、呼…」这类不带词义的短音，中日文剧情都不出戏。共 23 套声线：少女、姐姐、御姐、元气、妹妹，女声优式少年音，以及 15 个 VOICEVOX 男声；每套覆盖 20 种情绪。
- 角色设定里可为每个角色指定声线、音高和语速，带试听；「自动」会按角色设定判断性别并固定分配一套。旁白、心里话和 NSFW 场景不发声。
- 语气音的左右位置跟着立绘走，电话那头的声音像从听筒里传来；发声时背景音乐和打字音会让一让。总开关、播放时机和音量在「演出 › 声音」。

#### 🎁 拿到东西终于有感觉
- 数据库物品表里多了或少了物品，会自动演出「获得 / 失去」，不用等 AI 写物品标签；演出出现在正文第一次提到这件物品的那一页。
- **第一次拿到**的物品走画面中央的完整演出：立绘和对话框暂时退场，光芒中亮出物品和名字，结束时飞进背包、立绘回来。再次提到、失去或用掉的物品，在右上角弹一张小卡片。
- 右上角的卡片换成了每套对话框皮肤专属的边框；没有物品图时，按物品名显示钥匙、信、药水等对应图标。
- 正文里已经拿到的物品名会被点亮，点一下就能看这件物品的卡片（可在设置里关闭）。

#### 🍙 吃东西也是一场戏
- 日常演出新增「吃东西」（需单独勾选）：角色头上按漫画分镜一拍一拍演——眼睛发亮流口水、「啊呜」一口、「嚼嚼」、「咕咚」，最后按味道给反应：好吃开小花、辣到喷火、烫得哈气、酸得皱成一团、噎住捶胸……立绘也会跟着前探、咀嚼、蹦一下。喝东西是「咕嘟咕嘟——噗哈～」；喂对方吃时冒出「啊～」气泡，被喂时先脸红。
- 漫画符号新增 12 个进食符号，也能被「嘴馋」「满足」「吃饱」等情绪词单独触发。
- 物品表里的食物被吃掉、喝掉时，卡片会被咬掉两口、掉下碎屑，或者杯子一倾冒出气泡。

#### 🎬 更多演出
- 语音通话默认改成左右斜切的分屏，说话的一方亮起；原来的头像小窗仍可选。地点 / 时间标题卡跟随对话框皮肤配色。
- AI 可以下镜头指令：特写、拉远、虚化、摇镜、倾斜（需打开「镜头语言」）。
- 亲密演出新增感官调度（蒙眼、耳边、触碰、屏息等）、CG 运镜与脱衣扫光，以及独处场景（独处声景、怕被发现的动静、想象中的对象）。
- 演出写法只在剧情真的用得上时才发给模型：说到镜头、做饭、测体温、吃东西等，或 AI 上一层刚用过，才补发完整写法，平时只占很少的提示词。

#### 🎵 背景音乐更贴场景
- 曲库扩充到 80 首，各世界观都补了日常曲；场景对不上的曲目会让位，魔法街道不再配宫廷乐。
- 音乐接入统一混音：回忆、梦境里音乐真的会变闷，iPhone 上淡入淡出也生效；进战斗快切、转悲伤慢慢过渡；告白、真相揭晓这类瞬间会让音乐停下来留白。

#### ⚙️ 配置、素材与排查
- 全局设置（主设置、阅读器设置、预设库、场景预设、素材文件夹等）会同步到酒馆的 `user/files/igs-settings.json`：换设备、换浏览器、清缓存后自动恢复，改动约 1.5 秒后保存过去。聊天里的进度、日志等仍只留在本机。
- 已生成的场景缺当前时段（清晨 / 白天 / 黄昏 / 夜晚）的图时，会自动补一张同场景的时段图。
- 自动补物品图时，只把提到物品的那几段正文交给副 LLM，比之前省 token。
- 设置页新增「复制本页诊断」：说明当前页的立绘、背景、CG 为什么显示成这样，自动去掉正文和图片，可以直接贴出来求助。
- 修复角色设定里「声线」「学院」选了保存不了的问题。

#### ⚠️ 老用户请留意
- **配置首次同步**：如果你在多台设备上都用过，先打开新版本的那台会把它的配置存进酒馆，之后打开的设备会换成这一份（不会合并）。想保留哪台的配置，就先在哪台打开。
- 酒馆的「数据清理」仍可能把 `igs-*` 图片目录里的图片标为未引用，清理前不要直接勾选删除。
- 语气音、吃东西演出默认关闭；物品演出跟随「获得物品演出」开关。已安装的自动更新导入件无需重新导入，重新加载酒馆即可。

#### 🎬 剧情演出有了新的选择

#### 🎨 立绘和图片生成更灵活
- 角色立绘可选开启轮廓增强，自选描边或投影、颜色和强度；编辑立绘时暂时关闭，方便看清原图。剧情 CG 也可选在对话框左侧显示说话人的裸体立绘头像，旁白时隐藏，默认关闭。

- 场景与角色素材可以上传图片；素材预设可以确认后用当前素材覆盖，也能把图片一起导出。角色和场景区可分别下载当前筛选出的素材。
